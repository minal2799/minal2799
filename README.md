## 🚀 Featured Projects

### [Airbnb End-to-End Data Engineering Pipeline](https://github.com/minal2799/Airbnb-End-to-End-Data-Engineering-Project)
ELT pipeline that moves raw Airbnb data from S3 into Snowflake, transforms it with dbt, and schedules it with Airflow.
